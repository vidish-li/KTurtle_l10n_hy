### ⚠️ Կարևոր է իմանալ

Արխիվի մեջ բացի հիմնական `kturtle.mo` թարգմանության ֆայլից ավելացված է նաև `kturtle-vidish.mo` թարգմանության ֆայլը։ `kturtle-vidish.mo` ֆայլը պարունակում է հայերեն հրամանների իմ կողմից ձևափոխված տարբերակը։ Ձևափոխված տարբերակում կատարված փոփոխությունների հակիրճ բնութագրությունն ու հիմնավորումները ստորև․

1. Հրամանների բայերի հրամայական եղանակները փոխարինվել են բայերի անորոշ դերբայներով, օր․՝ «հարցրու» → «հարցնել», «ստուգիր» → «ստուգել»։ 
**Հիմնավորում։** Թեպետ հրամայական եղանակով  հանդիպում են նաև այլ թարգմանություններ (օր․՝ ռուսերենը), այնուամենայնիվ այն հնչում է արհեստածին, քանի որ օրինակ ծրագրերի հայաֆիկացված միջերեսներում մենք ունենք «Բացել», «Չեղարկել», «Խմբագրել» ևն բայց ոչ «Բացի՛ր», «Չեղարկի՛ր», «Խմբագրի՛ր», ուստի նման մոտեցում կարելի է կիրառել նաև հրամանների դեպքում։ Բացի այդ, անգլերեն սկզբնալեզվով ծրագրային ապահովման մեջ, օրինակ՝ Print բայը պարտադիր չէ ընկալել դրա հրամայական եղանակով (տպիր)։ Օգտատիրոջ տեսանկյունից ընկալումը կարող է լինել հետևյալ կերպ․ I want to **Print** my document → **Print** my document → **Print**։

2. Որոշ հրամմանների ավելացվել է **ը** հոդը, օր․՝ «կտավիգույն» → «կտավիգույնը»։
**Հիմնավորում։** Թեպետ ծրագրային ապահովման մեջ պարամետրերի կոնկրետացումը երկրորդական է, այնուամենայնիվ, օրինակ «ուղղությունը 90» և «ուղղություն 90» ընտրության մեջ, առաջինը հայերենում հնչում է ավելի բնական (օրգանիկ)։ Բացի այդ՝ **ը** հոդի ընտրության արդյունավետությունը հանդիպում է նաև այլ ծրագրերում [տես Scratch, Աղվես)։

3. Ավելացվել են որոշ հրամանների կրճատ հայերեն տարբերակներ, օր․՝ «գրիչիգույնը» → «գգ»։

4. Կատարվել են բառային փոփոխություններ այն դեպքերում, երբ գտնվել է տվյալ կոնտեքստին համապատասխան ավելի բնական այլընտրանքային բառ։ **Հիմնավորում։** Օրինակ՝ «մաքրել» հրամանը փոխարինվել է «ջնջել» հրամանով իմաստային նուրբ տարբերությունների պատճառով, օր․՝ «ռետինով ջնջել գծագիրը», բայց «մաքրել պատուհանը», «մաքրել գրատախտակը»։ Այսինքն՝ մաքրել բառը իմաստային առումով ավելի մոտիկ է կեղտը, փոշին ևն հեռացնելու գործողությանը։ Կարելի է անալոգիայով համեմատել անգլերեն «to clear»֊ն ու «to clean»֊ը, որտեղ «to clear»֊ն ավելի մոտ է ջնջելուն, իսկ «to clean»֊ը՝ մաքրելուն։ 

5. «վասն․․առ» բառերը (for..to) փոխարինվել են «ամեն․․մինչև» բառերով։ **Հիմնավորում։** Թեպետ «վասն» գրաբարյան նախդիրն այս կոնտեքստում կարող է լրիվ համահունչ թվալ, այնուամենայնիվ, նման բառերի ընտրությունը ուսուցողական և ընկալման տեսանկյունից կարող է լինել խնդրահարույց, մանավանդ երիտասարդ լսարանի դեպքում։ Մյուս կողմից՝ օրինակ «ամեն $x = 0 մինչև 10 քայլ 2» լիովին արտահայտում է for ցիկլի գործողության սկզբունքը, այսինքն՝ 1֊ից 10֊ն ընկած 2 քայլ ինկրեմենտով **ամեն** x-ի համար։ 

6. Գրիչ բառի հոլովման դեպքում ի տառի սղումը չեղարկվել է, օրինակ՝ «գրչիգույն» → «գրիչիգույնը» (ը հոդի ավելացման մասին տես վերևում)։ **Հիմնավորում։** ի տառի սղումը հայերնում լրիվ բնական է, սակայն «գրիչի» բառաձևը արդի հայերենում նույնպես հանդիպող և ընդունված է [(տես nayiri.com մեջբերումներ ➚)](http://www.nayiri.com/search?dt=HY_HY&r=0&l=hy_LB&query=%D5%A3%D6%80%D5%AB%D5%B9%D5%AB)։ Բացի այդ, «գրչի» բառաձևն առավել ընդունված է կիրառել գրողների, պատմիչների, հեղինակների, ինչպես նաև՝ իմաստապես ավելի տարողունակ դեպքերում և ոչ նկատի ունենալով առարկաներ, ինչպիսիք են, օրինակ, գնդիկավոր գրիչը [(տես nayiri.com մեջբերումներ ➚)](http://www.nayiri.com/search?dt=HY_HY&r=0&l=hy_LB&query=%D5%A3%D6%80%D5%B9%D5%AB)։ 

7. «Կեղծ» բառը փոխարինվել է «սխալ» բառով։ **Հիմնավորում։** Եթե մենք ընտրում ենք «կեղծ» բառը, ապա դրան համապատասխան պիտի ընտրենք «ճշմարիտ» այլ ոչ «ճիշտ» բառը, ինչպես ներկա թարգմանության մեջ [(տես («Ասույթների տրամաբանություն» ➚)](https://hy.wikipedia.org/wiki/%D4%B1%D5%BD%D5%B8%D6%82%D5%B5%D5%A9%D5%B6%D5%A5%D6%80%D5%AB_%D5%BF%D6%80%D5%A1%D5%B4%D5%A1%D5%A2%D5%A1%D5%B6%D5%B8%D6%82%D5%A9%D5%B5%D5%B8%D6%82%D5%B6)։ Ուստի եթե որոշում ենք «ճիշտ» բառը պահել (իր հակիրճության հիմնավորմամբ), ապա դրան համապատասխանում է «սխալ» բառը։

Թարգմանության ձևափոխված տարբերակն օգտագործելու համար պարզապես անհրաժեշտ է․

1. Ապաարխիվացմած ֆայլերի մեջ ջնջել **kturtle.mo** ֆայլը
2. Վերանվանել **kturtle-vidish.mo** ֆայլը և դարձնել **kturtle.mo**
3. Նորից պատճենել **usr** թղթապանակը համակարգի գլխավոր դիրեկտորիա **/**՝ օգտագործելով ադմինիստրատիվ իրավունքներ **(sudo)**


  ```bash
    sudo cp -r KTurtle_l10n_hy/usr/ /
  ```
